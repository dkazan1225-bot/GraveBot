# GraveBot 1.0 — экспериментальное отслеживание клеток

Проект Android (Android 8+, проверять на Android 14). Это исходный код, не готовый APK.

## Что добавлено
- Захват экрана через MediaProjection.
- Поиск пяти клеток с серыми надгробиями по последовательным кадрам.
- Ожидание превращения объектов в тыквы.
- Создание локального RGB-шаблона для каждой из пяти целей.
- Сопоставление шаблонов в соседних кадрах с поиском вокруг последней позиции.
- Панель поверх игры показывает текущие найденные клетки оранжевым; если совпадение потеряно, клетка становится неопределённой.

## Важные ограничения
Это экспериментальный patch tracker, а не обученная модель. Он использует небольшой участок изображения вокруг объекта и контекст фона. Если пять тыкв визуально одинаковы, перекрываются, резко телепортируются дальше окна поиска или анимация сильно меняет вид, индивидуальность объекта может быть потеряна. В таком случае приложение оставляет цель неопределённой. Зелёные безопасные клетки намеренно не показываются: алгоритм пока не доказывает, что остальные клетки безопасны.

## Настройка поля
Начальные значения для скриншота 720×1600: X=7%, Y=25%, W=86%, H=37%. Это прямоугольник доски в координатах всего захваченного экрана. Если браузер/масштаб меняется, настройте его в главном окне.

## Сборка APK простым способом через GitHub
1. Создайте репозиторий GitHub и загрузите всё содержимое архива.
2. В Actions запустите workflow `Build GraveBot APK`.
3. Скачайте artifact `GraveBot-debug-apk`.
4. Установите APK на Android и выдайте разрешение на показ поверх других приложений и захват экрана.

## Использование
1. Запустите GraveBot.
2. Разрешите отображение поверх других приложений.
3. Нажмите «Показать панель».
4. Нажмите «Начать захват и анализ» и подтвердите системное окно Android.
5. Вернитесь в игру и начните раунд. Оставьте захват включённым до окончания перемешивания.

Частота обработки ограничена примерно 30 кадрами/с, но реальная частота зависит от производительности телефона и сложности кадра. Тестирование на конкретном устройстве обязательно.
